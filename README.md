# Avante Club — MVP v0.2

Plataforma gratuita da Avante Mobi para experiência, pós-venda e relacionamento.

## Funcionalidades
- Minha Moto com cadastro local no aparelho
- Manual & Cuidados
- Garantia de 1 ano para bateria e motor
- Atendimento via WhatsApp
- Solicitação de revisão via WhatsApp
- Avante Indica com R$100 por venda confirmada
- Catálogo inicial: V7 Pró, X13 e X15
- Endereço, horário e Instagram
- Estrutura PWA instalável em HTTPS
